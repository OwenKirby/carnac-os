CARNAC OS

Install Carnac

Works in Chrome or Edge on a computer, with the FM1 connected by USB. Nothing to install on the computer. Your saved patches stay on the FM1. Coming from Carnac 0.9.1, sequences and performances saved with it do not carry over.

1Connect the FM1 straight to the computer with a USB data cable, switch it on, and close other apps that use MIDI.
2Press Find my FM1. The browser asks to allow MIDI: allow it.
3Press Install. It takes about three minutes: the firmware, then the PCM waves (the FM1 goes quiet for moments while they are written). Do not unplug the cable or close this page while it writes.

Enjoying Carnac? It's free; tip me if you like it.

If something goes wrong

  
If the install stops part-way, replug the cable and press Find my FM1 again: the FM1 stays in
    update mode until it is finished, and this page carries on from there.

  
If the FM1 doesn't start after an update, switch it off and on twice. After two failed starts it
    starts in safe mode, which keeps USB working, so this page can install again.
